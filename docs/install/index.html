Heads-up

A full install erases the whole flash, including saved Wi-Fi settings and calibration. Flash the variant that matches your display: 1.8", 1.77", or Nextion. Connecting a Nextion build to an ST7735 panel (or the reverse) leaves the local screen blank.

Counter reset: momentary button GPIO33 to GND (internal pull-up, active low).
